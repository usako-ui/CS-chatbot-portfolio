1ログイン

管理画面URL
  1. 上記のURLを開き、メールアドレスとパスワードを入力します。
  2. 「ログイン」を押すと、未対応の問い合わせ件数が表示されます。

2返信の手順

  1. 左の一覧から問い合わせをクリックします。
  2. 右下のテキストボックスに返信を入力します。
  3. Enterキーで送信します。 改行したいときは Shift + Enter

3対応完了の操作

解決したら、右上の対応完了ボタンをクリックします。

4よくあるトラブルと対処法

チャットの一覧が表示されない

ページを再読み込み（F5）してください。改善しない場合はログアウトして再ログインしてください。

返信が送れない

画面上部に「通信に失敗しました」と表示される場合は、ネットワーク接続を確認して再度お試しください。

新着の問い合わせが自動で表示されない

ページを再読み込みしてください。通常は自動で更新されますが、長時間操作しない場合に止まることがあります。

ログインできない

パスワードを確認してください。それでも入れない場合はシステム管理者にお問い合わせください。

印刷のしかた
  • ブラウザでこのファイルを開き、Ctrl + P（Macは Cmd + P）を押します。
  • 用紙サイズは「A4」、余白は「標準」を選びます。
  • 「背景のグラフィック」をオンにすると見やすくなります。
