1ログイン

管理画面URL
  1. 上記のURLを開き、メールアドレスとパスワードを入力します。
  2. 「ログイン」を押すと、未対応の問い合わせ件数が表示されます。

2返信から対応完了まで

  1. 左の一覧から問い合わせをクリックします。
  2. 右下のテキストボックスに返信を入力します。
  3. Enterキーで送信します。 改行したいときは Shift + Enter

解決したら、右上の対応完了ボタンをクリックします。

3本日休業フラグの正しい使い方

画面右上のボタンで切り替えます（本日対応中＝通常営業／本日休業＝営業時間内でも時間外と表示）。 会社全体が急遽休業になる場合のみ使ってください。

○ 使う場面

  • 台風・災害などで全員出社できなくなった
  • 社内イベントで対応できない日
  • システムメンテナンスで対応を停止する日

× 使わない場面（よくある誤操作）

  • 個人の退席・早退 → ログアウトするだけでOK
  • 定休日・祝日 →「定休曜日」「休日登録」で事前に登録

押すと全お客様へ休業と表示されます。

翌日になっても自動では戻りません。翌営業日の朝、画面右上のボタンで 「本日対応中」に戻してください。戻し忘れると営業時間内でも時間外メッセージが出続けます。

4よくあるトラブルと対処法

チャットの一覧が表示されない

ページを再読み込み（F5）。改善しない場合はログアウトして再ログインしてください。

返信が送れない

「通信に失敗しました」と出る場合は、ネットワーク接続を確認して再度お試しください。

新着の問い合わせが自動で表示されない

ページを再読み込みしてください。長時間操作しないと自動更新が止まることがあります。

お客様の画面に「担当者に接続しています。」と出ている

AIが動かなかった合図です（AIの回答ではありません）。問い合わせは届いているので通常どおり返信してください。

返信したのにお客様の画面に出ない

お客様がチャットを閉じているだけです。次に開いたとき表示されます。読まれる前に「対応完了」にすると履歴が消えます。

ログインできない

パスワードを確認し、それでも入れない場合はシステム管理者にお問い合わせください。

印刷のしかた
  • ブラウザでこのファイルを開き、Ctrl + P（Macは Cmd + P）を押します。
  • 用紙サイズは「A4」、余白は「標準」を選びます。
  • 「背景のグラフィック」をオンにすると見やすくなります。
